    ÎNȚELEGE / REPRODU

    Metodologie

    Cum se construiește o estimare și unde se oprește informația.

    01 / MODELE

    Trei abordări, același rezultat

    KNN estimează rezultatul din partide cu variabile similare. Random Forest combină arbori de decizie. Poisson estimează golurile așteptate și distribuția scorurilor, din care se obțin probabilitățile 1 / X / 2.

    02 / TIMP, NU AMESTECARE ALEATORIE

    Doar informație din trecut

    Variabilele unei partide sunt calculate numai din meciurile anterioare ei. Antrenarea, validarea și testarea sunt separate cronologic. Evaluarea walk-forward înaintează în timp fără a folosi rezultate viitoare; protocolul și intervalele efective apar în Experimente. Hiperparametrii se aleg pe validare, nu pe test.

    03 / CITIREA RAPORTULUI

    Mai mult decât acuratețe

    Acuratețea și macro F1 se interpretează în sens crescător. Log loss și Brier se interpretează în sens descrescător și evaluează probabilitățile. Matricile de confuzie arată clasele confundate: rânduri = rezultat real, coloane = rezultat prezis, în ordinea 1, X, 2. Un eșantion mic de test limitează concluziile.

    04 / LIMITE

    Istoricul nu este un flux live

    Limita temporală este dată de ultimul meci din CSV-ul încărcat.

    Nu sunt cunoscute automat accidentările, transferurile, cotele sau schimbările de lot. O dată de predicție viitoare nu adaugă informație nouă. Probabilitățile nu garantează rezultatul; proiectul nu oferă consiliere financiară.

    05 / REPRODUCTIBILITATE

    Păstrează sursa și raportul

    Importă CSV-ul, antrenează, inspectează Experimente și exportă fișierele raportului. Păstrează sursa alături de parametri, intervale și rezultate pentru a putea reproduce analiza.
